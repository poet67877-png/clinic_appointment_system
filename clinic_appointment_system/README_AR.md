# ClinicPlus - منصة إدارة المواعيد الطبية

منصة SaaS متعددة العيادات (Multi-tenant) متكاملة لإدارة المواعيد الطبية، مبنية بـ React و Node.js و PostgreSQL.

## 🏗️ البنية التقنية

| المكون | التقنية |
|-------|---------|
| **Frontend** | React 19 + TypeScript + Tailwind CSS 4 |
| **Backend** | Node.js + Express + tRPC |
| **Database** | MySQL/TiDB مع Drizzle ORM |
| **Auth** | JWT + OAuth |
| **Storage** | S3 |
| **QR Code** | react-qr-code |

## 🚀 البدء السريع

### 1. التثبيت

```bash
git clone https://github.com/yourusername/clinicplus.git
cd clinic_appointment_system
pnpm install
```

### 2. إعداد البيئة

انسخ `.env.example` إلى `.env` وعدّل البيانات:

```env
DATABASE_URL="mysql://user:password@localhost:3306/clinicplus"
JWT_SECRET="your-secret-key"
NODE_ENV="development"
PORT=3000
```

### 3. إعداد قاعدة البيانات

```bash
pnpm drizzle-kit generate
pnpm drizzle-kit migrate
```

### 4. التشغيل

```bash
# التطوير
pnpm dev

# الإنتاج
pnpm build
pnpm start
```

الموقع سيكون متاحاً على `http://localhost:3000`

## 🔄 دورة حياة الموعد

1. **المريض** يحجز موعد من الصفحة الرئيسية
2. **النظام** يتحقق من توفر الموعد
3. **المريض** يستقبل تأكيد برمز فريد
4. **العيادة** ترى الموعد في لوحة التحكم
5. **المريض** يستقبل تذكير قبل الموعد
6. **العيادة** تؤكد أو تلغي الموعد
