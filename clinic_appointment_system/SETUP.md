# عيادة النور - نظام حجز المواعيد

منصة SaaS متعددة العيادات (Multi-tenant) لإدارة حجز المواعيد الطبية باللغة العربية.

## الميزات الرئيسية

### للمرضى
- ✅ حجز مواعيد سهل وسريع
- ✅ اختيار الطبيب والتاريخ والوقت
- ✅ تأكيد فوري برمز تأكيد فريد
- ✅ عرض وإلغاء المواعيد

### للعيادات
- ✅ نظام تسجيل ذاتي
- ✅ لوحة تحكم متكاملة
- ✅ إدارة الأطباء والأوقات المتاحة
- ✅ إحصائيات يومية وشهرية
- ✅ نطاق فرعي خاص بكل عيادة

### للمسؤول الأعلى
- ✅ لوحة تحكم Super Admin
- ✅ مراقبة جميع العيادات
- ✅ إحصائيات شاملة
- ✅ إدارة الخطط والاشتراكات

## البنية التقنية

### Frontend
- React 19 + TypeScript
- Tailwind CSS 4 (Dark Theme)
- tRPC للاتصال بالـ Backend
- Wouter للتوجيه
- Shadcn/UI للمكونات

### Backend
- Node.js + Express
- tRPC للـ API
- Drizzle ORM لقاعدة البيانات
- JWT للمصادقة

### Database
- MySQL / TiDB
- جداول معزولة بـ clinicId

## الصفحات الرئيسية

1. **الصفحة الرئيسية** (`/`)
   - قائمة الأطباء
   - إحصائيات سريعة
   - روابط سريعة

2. **حجز الموعد** (`/book`)
   - نموذج متعدد الخطوات
   - اختيار الطبيب والتاريخ والوقت
   - إدخال بيانات المريض

3. **تأكيد الحجز** (`/confirmation`)
   - ملخص الموعد
   - رمز التأكيد
   - خيارات الطباعة

4. **عرض المواعيد** (`/appointments`)
   - البحث برقم الهاتف
   - عرض المواعيد
   - إمكانية الإلغاء

5. **تسجيل عيادة** (`/register`)
   - نموذج التسجيل
   - التحقق من النطاق الفرعي
   - إنشاء حساب المسؤول

6. **لوحة تحكم العيادة** (`/clinic/dashboard`)
   - نظرة عامة
   - إدارة المواعيد
   - إدارة الأطباء
   - الإعدادات

7. **لوحة تحكم Super Admin** (`/admin/super`)
   - مراقبة العيادات
   - الإحصائيات الكلية
   - إدارة الخطط

## البيانات الافتراضية

### الخطط المتاحة
1. **خطة مجانية** - حتى 3 أطباء و 100 موعد شهري
2. **خطة احترافية** - حتى 10 أطباء و 500 موعد شهري
3. **خطة مؤسسية** - حتى 50 طبيب و 5000 موعد شهري

## النطاقات الفرعية

كل عيادة تحصل على نطاق فرعي فريد:
```
https://[clinic-slug].manus.space
```

مثال: `https://clinic-noor.manus.space`

## المصادقة

- **OAuth**: تسجيل دخول عبر Manus
- **JWT**: للمصادقة بين الـ Frontend والـ Backend
- **Multi-tenant**: عزل كامل للبيانات بين العيادات

## عزل البيانات

جميع الاستعلامات مفلترة حسب `clinicId`:
- لا يمكن لعيادة الوصول إلى بيانات عيادة أخرى
- كل مستخدم يرى فقط بيانات عيادته
- المسؤول الأعلى يرى جميع البيانات
